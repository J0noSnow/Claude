# Dan Koe letter summaries

Paraphrased notes (my own wording, not copies) on Dan Koe's newsletters, built for the Jono's Journal playbook.

- `b01.md` to `b16.md`: notes on 222 free letters (thedankoe.com archive and free Substack posts), 14 letters per file, tagged by theme.

Theme tags: [A] audience growth, [N] newsletter craft, [L] email-to-product ladder and launches, [C] courses and products, [I] idea generation and articulation. DEMO = something he says he did. OPINION = his claim.

The raw letter text is not stored here.
